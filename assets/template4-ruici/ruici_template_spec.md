# 瑞慈版本模板：结构与视觉抽取规格 v3.2

## 提取来源与边界

来源：`剑指"癌王"：长海医院协手瑞慈体检，正在改写胰腺癌终局.html`。

- 原文的可用编辑主体为 `#js_content`；微信平台 chrome、运行时节点不纳入模板。
- 原文核心叙事结构：Hero 首图 → 白色叠层装饰条 → 连续 6 张视觉叙事图 → 高危转诊预约卡 → 浅蓝圆点分隔 → 往期回顾 → 3D GIF 尾饰 → 点赞/分享/收藏行。
- 模板保留视觉语言，但所有新标题、正文和 CTA 使用真实 HTML 文本。

## v3.1 统一色号（重要）

**只使用原文 HTML 实际出现的色号，不自创绿色变体**。从原文 `js_content` 提取的精确色号：

| 色号 | 用途 | 对比度 |
|---|---|---|
| `#3a7945` | 标题、品牌条、边框、强调文字 | 绿字白底 → 优秀 |
| `rgba(171,212,191,.3)` | 薄荷卡底（标题栏、预约卡） | 绿字薄荷底 → 可接受 |
| `rgba(171,212,191,.15)` | 对比卡内容区浅薄荷底（比标题栏浅一级，保证正文对比度） | 深字浅底 → 良好 |
| `#c73e3e` | 行动红、警告文字 | 红字白底 → 优秀 |
| `#c7e1f7` | 浅蓝分隔圆点、引用框左边线 | 装饰用 |
| `#90d7ec` | 青蓝附录边框、虚线框 | 装饰用 |
| `#114287` | 深蓝附录标题 | 装饰用 |
| `#3e3e3e` | 正文文字（17px） | 正文字白底 → 优秀 |
| `#607fa6` | 链接 | 链接白底 → 良好 |

**文本框浅色背景设计（原文确认）**：原文内容卡/预约卡整体为薄荷绿浅底 `rgba(171,212,191,.3)` + 圆角 14–15px + 2px 边框 + 浅色外阴影（`rgb(236,249,255) 5px 5px`）+ 白色内阴影。生成文章时，对比卡内容区不得用纯白底，应使用 `rgba(171,212,191,.15)` 浅薄荷底（保留标题栏 `.3` 与内容区 `.15` 的层次）。

## 字体与段落

- 字体：系统中文无衬线栈；不强制使用特殊 webfont。
- 正文：`16–17px`、`line-height:1.9–2`、`letter-spacing:.034em`、两端对齐。
- 每段 1–3 句，约 3–4 个移动端行；一个段落只传达一个意思。
- 中文标题为主，英文副标题仅在内容有真实英文主题/栏目名时使用，避免为了装饰硬加英文。

## 模块顺序（v3.1）

1. **品牌条**：绿底 `#3a7945` + logo + 项目名 + 副标题
2. **标题卡片**：错位浮动白卡 + 胶囊标签 + 主标题 + 副标题
3. **元信息**：账号/日期/地域（低对比灰）
4. 可选 Hero 图
5. 可选连续视觉叙事（1–6 张图片）
6. 正文（ruici 段落 + 章节标题 + 对比卡片 + 信息框）
7. 可选 HighRiskReferralCard（只在有真实预约/地址/电话/QR 时使用）
8. 浅蓝圆点分隔（RuiciDivider）
9. 可选 RelatedReading（0–3 条）
10. 来源/引用块
11. 可选静态互动提示
12. **Foot（完整版 v3.2）**：关于小胰宝深绿卡 → **尾图**（mmbiz 社区大图，width:100%）→ 关注我们白卡 → 底部寄语（🌿🍃）→ 免责声明
