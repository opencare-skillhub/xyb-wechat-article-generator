# 瑞慈版本模板：结构与视觉抽取规格

## 提取来源与边界

来源：`剑指“癌王”：长海医院协手瑞慈体检，正在改写胰腺癌终局.html`。

- 原文的可用编辑主体为 `#js_content`；微信平台 chrome、运行时节点不纳入模板。
- 原文核心叙事主要由首图和连续 6 张图片构成。图片中烘焙的标题、正文和英文文字不能作为模板可编辑内容复用。
- 模板将保留视觉语言，但所有新标题、英文副标题、正文和 CTA 使用真实 HTML 文本。

## 视觉 Token

| 名称 | 值 | 用途 |
|---|---|---|
| 正文墨色 | `#3E3E3E` | 16–17px 正文 |
| 医疗主绿 | `#3A7945` | 服务标题、行动线索 |
| 薄荷背景 | `rgba(171,212,191,.3)` | 转诊/预约卡 |
| 行动红 | `#C73E3E` | 预约行动语 |
| 浅蓝 | `#C7E1F7` | 分隔圆点 |
| 青蓝 | `#90D7EC` | 附录左轨、虚线框 |
| 深蓝 | `#114287` | 附录标题 |
| 链接蓝 | `#607FA6` | 可点击链接 |

## 字体与段落

- 字体：系统中文无衬线栈；不强制使用特殊 webfont。
- 正文：`16–17px`、`line-height:1.9–2`、`letter-spacing:.034em`、两端对齐。
- 每段 1–3 句，约 3–4 个移动端行；一个段落只传达一个意思。
- 中文标题为主，英文副标题仅在内容有真实英文主题/栏目名时使用，避免为了装饰强加英文。

## 模块顺序

1. 可选 Hero 图
2. 中文标题 + 可选英文副标题 + 摘要
3. 导语
4. 正文（中英标题组件、短段落、真实图表）
5. 可选 HighRiskReferralCard（只在源文有真实预约/地址/电话/QR 时使用）
6. 可选 RelatedReading（0–3 条）
7. 可选静态互动提示
8. Foot

## 原文结构的映射

- 原文高危转诊预约卡 → `HighRiskReferralCard`
- 原文蓝色圆点分隔 → `RuiciDivider`
- 原文“往期回顾” → `RuiciRelatedReading`
- 原文 3D GIF 尾饰 → 可选 `RuiciEndFlourish`，不使用 3D transform
- 原文“点赞/分享/收藏” → 静态互动提示；不得伪造原生微信控件

## 图片规则

- 图片统一 `width:100%;height:auto;display:block`。
- 不保留原文固定 `578px × 215px` 等尺寸。
- 默认 COS 基址可替换：`ASSET_BASE_URL = user_base || xyb_default_base`。
- 不上传患者隐私、检查报告、身份信息、Token 或 AppID。
