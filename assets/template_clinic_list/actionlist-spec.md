# actionlist 系列模版规范（行动清单 / 步骤指南风）

> 适用：**按步骤执行的科普 / 行动指南 / 确诊后怎么办 / 流程类 / 清单体**内容。
> 设计语言提取自「诺康癌友圈」一篇胰腺癌确诊指导文章，特点是朴素耐读、节奏强、指向明确。
> 与 template_bm（杂志快讯·深底 Hero）路线完全不同：本系列**不靠视觉冲击，靠"照着做"的确定感**。
> 六色：蓝（基准）/ 紫 / 绿 / 橙 / 红 / 青，全部通过 WCAG 对比度校验。

## 一、设计 Token（8 个颜色变量，六色共用一套结构）

| Token | 角色 | 出现位置 |
|---|---|---|
| `{{C_INK}}` | 深墨色（"骨"） | 巨型数字底、编号圆底 |
| `{{C_TITLE}}` | 标题色 | 章节 h3、引言大字、卡片小标题、强调文字 |
| `{{C_TEXT}}` | 正文色 | 正文段落、列表项文字 |
| `{{C_MUTED}}` | 辅助灰蓝 | 英文小标、卡内序号、灰色说明、END 字 |
| `{{C_MAIN}}` | 主色（饱和度高，只占小面积） | 下划线强调、编号圆点、竖条、英文小标 |
| `{{C_MAIN_RGB}}` | 主色 rgb | 浅色底透明度（本版未直接用，备用） |
| `{{C_TINT}}` | 浅底 | 巨型数字色、三栏看点卡底 |
| `{{C_LINE}}` | 描线 | 分隔线、卡片上边框、章节底线、END 左右线 |

**排版常量（六色一致）：**
- 正文 15px / line-height 1.8 / `text-align:justify` / `letter-spacing:0.3px`
- 巨型数字 44px / 900 字重 / `line-height:1` / `letter-spacing:-2px` / 色 `C_TINT`
- 英文小标 10px / `letter-spacing:3px` / 大写 / 色 `C_MAIN`
- 章节 h3 20px / 800 字重 / 色 `C_TITLE`
- 下划线强调：`border-bottom:2px solid C_MAIN`，文字色 `C_TITLE`
- 编号圆点 22×22 圆 / 底 `C_INK` / 白字 12px

## 三、组件清单（正文 11 个 + 固定 foot + 分隔线）

1. **引言 QUOTE 卡**（上下双细线 + 11px 英文标 + 18px 引言大字 + 下划线强调 + 右对齐署名）
2. **导语正文**（下划线强调关键词）
3. **本文看点三栏卡**（`flex` 均分 + `C_TINT` 底 + `C_LINE` 上边框 + 序号 + 加粗小标题）
4. **章节标题头**（44px 巨型浅色数字 + 10px 英文小标 + 20px h3 标题 + 底线）
5. **圆点编号列表**（22px 深墨圆底白字序号 + 悬挂正文）
6. **细分隔线**（章节之间 1px `C_LINE`）
7. **小标题（左竖条）**（3px 主色竖条 + 加粗文字）
8. **行动提示条**（左竖条 + 16px 加粗大字，用于行动号召/关键提醒）
9. **灰色说明条**（2px 浅竖线 + 13px `C_MUTED` 小字）
10. **写在最后（∞ 收口）**（∞ 巨型数字 + THE END + 收尾段落）
11. **END 收尾装饰 + 尾图落款**（左右 48px 细线 + END 字 + 顶线 + 品牌介绍 + 尾图 + 三连）

**分隔线（全站共用组件）：** 章节之间用「四段横线 + 居中植物 emoji」，横线取 `C_TINT → C_MAIN_TINT → C_MAIN`（左）/ 镜像（右），中间 emoji 20px。整篇只用一枚、同色系不变；需要换图标用 `scripts/pick-divider-icon.py --seed <日期> --tone <green|purple|warm>` 抽。

**固定 foot：** 复用小胰宝固定 foot 五件套（关于小胰宝深卡 → 尾图 → 关注我们 → 底部寄语 → 免责声明），结构与文案逐字照搬 template3 母版，仅按 actionlist 配色换色值（深卡底 `C_INK`、标题与「8个癌种」用 `C_MAIN_TINT`）。

**写作逻辑（actionlist 特有）：** 引言 → 导语 → 看点 → 分步骤展开（每步一个巨型数字章节 + 编号列表）→ 提示条 → 收口 → END + 落款。**强调一律用下划线**，不用荧光笔、不用卡片包裹，保持"文档感"。

## 四、图片规则（公网地址，硬约束）

- 所有 `<img src>` **必须是完整 https 绝对地址**；
- **禁止本地相对路径**（`xx.png` / `./xx.png` / `images/xx.png`）——本地 `file://` 预览正常，公众号内裂图；
- 路径**不得含 `%`、括号、空格、中文**——微信二次编码（`%20`→`%2520`）导致图床 404；
- 需要新图时用 `picgo-cos-upload` 技能上传到 COS，再把 `src` 换成返回的绝对地址；
- logo 用 `https://picgo-1302991947.cos.ap-guangzhou.myqcloud.com/images/xyb.png`。

- 触发词：「行动清单」「步骤指南」「确诊后怎么办」「照着做」「清单体」「流程科普」「actionlist」。
- 指定色：`actionlist 蓝色` / `actionlist 紫色` / …（未指定色默认**蓝色**，最贴合"医疗权威"直觉）。

- 遵守项目总规则：inline style + `<section>`、无 `<style>`/class、数据真实不得编造、下划线强调为本系列唯一强调手法。
