# bm 系列模版规范（前沿速讯风 / 提取自「刚刚BME」v2）

> 适用：新闻 / 资讯 / 前沿速递 / 研究亮点 / breaking 类内容。
> 设计语言提取自公众号「刚刚BME」一篇胰腺癌前沿快讯，重构为可复用、可换色的小胰宝模板家族。
> 与 template3（治愈系卡片错落）、template6-med（说明书权威）不同，bm 走「杂志快讯」路线：深底 Hero + 渐变大字 + 强对比胶囊 + 衬线导读。
> v2 变更：接入 XYB logo、导读 IN BRIEF、深底白字多档胶囊、受访专家缩写 logo 卡、接入小胰宝固定 foot。

## 一、设计 Token（9 个颜色变量，三色共用一套结构）

| Token | 角色 | 出现在 |
|---|---|---|
| `{{C_GRAD_A}}` | 品牌渐变·首段（渐变大字起笔；方块/圆图标第二段） | 渐变大字、图标、白卡标签、LOGO 字、**蓝底渐变胶囊** |
| `{{C_GRAD_B}}` | 品牌渐变·次段（同族浅调） | 渐变收尾、白卡标签收尾、**foot 深卡标题字/强调字**、小标签 |
| `{{C_ANCHOR}}` | 深色锚点（Hero/引用/深卡/页脚底）；也是**所有标题文字色** | Hero 底、引用框、foot 深卡底、H1/H2/小标题/列表项标题/专家名 |
| `{{C_ANCHOR_DARK}}` | 最深锚点 | Hero/页脚渐变收尾 |
| `{{C_ANCHOR_RGB}}` | 锚点 rgb（仅阴影透明度） | 悬浮卡/白卡阴影、关注我们卡边框、免责声明顶线 |
| `{{C_ACCENT}}` | 强调色 | BREAKING 胶囊、左竖条、行内代码、荧光笔高亮、Hero 副线、提示框左边框、关注我们标题、**深底白字胶囊底** |
| `{{C_ACCENT_RGB}}` | 强调色 rgb（仅浅底透明度） | 高亮底 `rgba(…,0.22)`、导读/提示框/专家卡浅底 `rgba(…,0.02~0.07)`、边框 `rgba(…,0.12)` |
| `{{C_TAG_BG}}` | 次级标签底（rgba 半透明） | Hero 栏目标签底 |
| `{{C_TAG_TEXT}}` | 次级标签字（同族） | Hero 栏目标签字+边框、**受访专家「受访专家」徽标底** |

**中性色（三色完全一致，硬编码）：**
- 浅卡底 `rgb(247,249,251)` / 边 `rgb(226,232,240)`
- 正文 `#2D3748`/`#3a3d50`/`rgb(51,60,77)`，次级 `#5b6478`/`#718096`，指标灰 `#6b7488`
- 章节底线/英文小标：`rgb(226,232,240)` / `#A6ADBD`
- 衬线字体（大数字/引用/导读/标题）：`Georgia,'Noto Serif SC','Songti SC',serif`
- 正文无衬线：系统字体栈（同项目规范）

| C_TAG_TEXT | `#F5A623` | `#8A4FD0` | `#1FAE7E` |

**配色策略（依据色彩理论 + 公众号排版规范）：**
- 60-30-10：中性浅底/白占 60%，同色系辅色 30%，高饱和强调色仅 10%（渐变大字、胶囊、左竖条、荧光笔）。
- 系列一致性：每个变体 = 「两段式品牌渐变 + 同族深色锚点 + 强调色」，结构零改动、只换色值。
- 可读性：浅卡白底配深灰正文（非纯黑）；强调色作小字时降到 WCAG 4.5:1 以上（紫 `#6E4FA3`、绿 `#137A57` 达标；橙 `#E94560` 仅作大字/边框/渐变/深底白字，不作正文）。
- 语义映射：橙=速递/突破能量；紫=胰腺癌宣传·高端编辑感；绿=生机/健康治愈（与 template3 既有配色语义一致）。

## 四、段落分隔规则（正文排版）

同一章节内的**连续正文段落**之间，加一个 bm 风格分隔件并保留留白，提升移动端阅读呼吸感：

- **分隔件（居中加粗短线）**：
  ```html
  <p style="text-align:center;margin:22px 0 20px;padding:0;line-height:1;">
    <span style="display:inline-block;width:88px;height:4px;background:linear-gradient(90deg, rgba({{C_ACCENT_RGB}},0) 0%, {{C_ACCENT}} 22%, {{C_ACCENT}} 78%, rgba({{C_ACCENT_RGB}},0) 100%);vertical-align:middle;border-radius:2px;"></span>
  </p>
  ```
  - 尺寸：**88×4px**（长宽比协调，手机端清晰可见），两端各约 22% 做渐隐，中间 56% 为实色，`border-radius:2px` 收圆。
- **段落留白**：正文段落 `margin-bottom` 约 4px + 分隔件上下共约 42px ≈ 1.5～2 行留白；也可按内容密度改为「只加分隔件」或「只加留白」。
- **使用位置**：同一章节的正文段落之间。**卡片之间不加**（卡片自身有边框/底色区分），列表卡、提示框、引用框、专家卡等模块边界不需要分隔件，保持克制。
- 分隔件是**段落级**的，不要每句都加，避免碎片化。

## 五、XYB logo 规则

- 头部悬浮信息卡左侧方框**内嵌 logo 图标**（50×50 圆角方框，`linear-gradient(135deg, C_ANCHOR, C_GRAD_A)` 底，logo 38×38 圆形 `object-fit:cover` 居中）。
- **唯一合法地址**（原样复制，末尾不带参数）：
  ```
  https://picgo-1302991947.cos.ap-guangzhou.myqcloud.com/images/xyb.png
  ```
- **禁止本地相对路径**（`xyb.png` / `./xyb.png` / `images/xyb.png` / `assets/images/xyb.png`）——本地 `file://` 预览正常，公众号内裂图；
- 路径**不得含 `%`、括号、空格、中文**——微信二次编码（`%20`→`%2520`）致图床 404。
  ```
  https://picgo-1302991947.cos.ap-guangzhou.myqcloud.com/images/xyb.png
  ```
- 受访专家卡用**圆形缩写 logo**（姓名首字母，如 `DS`/`AM`），非真人照片；渐变底 `linear-gradient(135deg, C_ANCHOR, C_GRAD_A)`。

## 六、固定 foot 规则（小胰宝五件套）

bm 系列的 foot **直接复用小胰宝固定 foot 结构与文案**（与 template3 一致），仅按 bm 配色替换色值：
1. **关于小胰宝深色卡**：`background:C_ANCHOR`；标题「🌿 关于小胰宝」与「8个癌种+1个罕见病」用 `C_GRAD_B`；正文白字 `opacity:0.9`。
2. **尾图**：沿用统一尾图 URL（`mmbiz.qpic.cn/.../640?wx_fmt=jpeg...`），`width:100%;border-radius:8px`。
3. **关注我们卡**：白底 + `border:1px solid rgba(C_ANCHOR_RGB,0.12)`；「📱 关注我们」用 `C_ACCENT`；正文 `#3a3d50`。
4. **底部寄语**：`🌿🍃` + 两行苹方细体寄语 + `With love and hope,` + 署名；文字 `#2D3748`/`#5b6478`。
5. **免责声明**：`border-top:1px solid rgba(C_ANCHOR_RGB,0.12)`，文字 `#6b7488`；参考文献为替换区。

> foot 文案**逐字不动**，只换色值。三色对应：橙（深蓝底+琥珀字）、紫（深靛底+淡丁香字）、绿（深林底+薄荷字）。

## 七、文件清单（assets/template_bm/）

- `bm_template.html` —— **token 化主骨架 v2**（9 个颜色 token + 内容占位 + logo + 导读 + 胶囊 + 专家 + foot），三色共用；生成时只输出 `.article` 内的 `<section>`/`<footer>`。
- `bm-template-橙色.html` / `bm-template-紫色.html` / `bm-template-绿色.html` —— 三色**已渲染示例**（橙色为母版，紫/绿由脚本派生）。
- `_derive_palettes.py` —— 从橙色稿派生紫/绿的脚本（保证三色结构一致，改橙色后重跑即可同步）。
- `bm-template-spec.md` —— 本规范。

## 八、路由建议（写入 skill.md）

- 触发词：「前沿速递」「快讯」「breaking」「研究亮点」「新闻资讯」「bm 模版」「bm 模板」。
- 指定色：`bm 橙色` / `bm 紫色` / `bm 绿色`。
- 未指定色时，默认 **bm 橙色**（= 源稿基准）。
- 与 template3/6 区分：bm 偏「杂志快讯 / 深底 Hero / 衬线导读」，template3 偏「治愈系卡片错落」，template6 偏「说明书权威」；新闻资讯类优先 bm。
- 遵守项目总规则：inline style + `<section>`、无 `<style>`/class、数据真实、foot 复用固定五件套。
